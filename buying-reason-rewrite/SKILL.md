# 买的理由：把卖点翻成决策句

## 核心框架

| | 卖点（X 语言） | **买的理由（Y 语言）** |
|---|---|---|
| 主语 | 我：我们有什么能力、做什么动作、懂什么原理 | 你：你会得到什么 |
| 读者动作 | **要推理**：自己换算成"所以我为什么要买" | **不用推理**：听完能决策 |
| 形态 | 参数、流程、方法论、服务清单 | 一句话结果，常带**比较级** |
| 数量 | 可以多 | **一句就够**，堆三句等于没有 |

**堆卖点 ≠ 买的理由强。**三条卖点加起来，不如一句结果。

### 小米案例（框架原型）

- `xx 处理器` / `xxx 能力` → 参数，读者自己换算
- `专为发烧友而生` → **伪装的卖点**：讲人群定位 ≠ 讲结果。这是最容易被误认成买点的一类
- `拍照更好看` → **买的理由**：结果可感知 + 比较级 + 不解释像素算法 + 就一句

### 三测试（一句是不是买的理由，逐条过）

1. 结果是**能直接感知**的吗？（不是"我们做了什么"，而是"你多了/少了什么"）
2. 有**比较级**吗？（原本 vs 现在 / 纯增量 / 多一条）
3. **需要解释机制**吗？——需要，就还是卖点。

### 两条留舍判据

- **内部语言不是都要清**，标准是「甲方听得懂吗」。听得懂的（如"入口问题"）可留；听不懂或要换算的（成本中心、利润中心、信源权重）必换。
- **标题不需要格式对齐**，看内容。别为了句式整齐牺牲准确性。

## 手法清单（逐条对照改，每条都有实测出处）

| # | 信号 | 原 → 改 | 判据 |
|---|---|---|---|
| 1 | 内部/财务/学术语 | 成本中心 → `直接节省岗位人力`；利润中心 → `原本会丢掉的单子，现在能重新拿回来` | 讲"你会多什么/少什么" |
| 2 | 两个功能并列罗列 | `AI 接待接住问一句就走的客人，销售管理盯住登了没跟的客资` → `AI 接住人类不愿意跟进的低意向客资` | 两个功能提炼成**一个**价值判断 |
| 3 | 定位/人群标签 | `专为发烧友而生` → 讲结果 | 标签是"我是什么"，不是"你会得到什么" |
| 4 | 相对位次表述 | `第三层 · 新渠道` → `增量渠道&品牌价值`；`最后这块` → `GEO 这块` | 「第 N 层」「最后这块」**依赖上下文铺垫**，孤立出现即失效；改用绝对价值表述 |
| 5 | 边界/免责独立成块 | `**先把边界说清：**它不取代…` → 直接续在价值陈述之后，另起一行 | 引导语"太硬"；续写后语气从**自证**变**顺带说明** |
| 6 | 短收尾句前的连词 | `而且这不是未来时` → `这不是未来时` | 短收尾句前的承接连词是冗余 |
| 7 | 重要内容被降级成注释 | `note：要有耐心…` → 升格为**同层级卡片**（编号接上 1-3 → 4） | 重要就升格，别藏在注释里 |
| 8 | 术语本身难改 | 服务名（信源权重速查卡等）**保留**，加一句 `一句大白话：…` | 术语不用硬翻，补一句结果式总结即可 |
| 9 | 同一结论出现多处 | 报告内结论 / 页面 note / 页面表格 → **只留报告**，其余降级为**指向它的导航** | 定唯一权威源（最详细的那份），其余不复述 |
| 10 | 拿到一段原材料 | 整段塞进开头 → **拆成内容点 → 逐点判"页面缺不缺 / 放哪"** | 禁止整段前置；**"参数堆得多"恰恰说明那句买的理由还没找到** |
| 11 | 结果不够可感知 | 加比较级：`原本会丢掉 → 现在能拿回来`、`纯增量`、`多一条产线` | 比较级让结果立刻可感知 |

## 执行流程

1. **通读全页**，把每块文案按「卖点 / 买的理由」分类列成表。先看清配比，再动笔。
2. **找那一句**：整页有没有一句「拍照更好看」——首屏能不能一句话说清为什么买。没有就先找，别在参数层打转。
3. **逐条套手法清单**，一条一条改；用户给的是整段定稿时**整段替换**，并显式报出删掉了什么。
4. **位次词复检**：只要页面排序或编号变过，扫全站的「第 N 层 / 最后 / 前几块 / 首个」——排序一变它们就失效。
5. **重复度终检**：结论性数字/判断，全页只留一份，其余做导航。

## 完成判据

- 首屏有一句不需要推理的**买的理由**（通过三测试）。
- 卖点区块（服务项、机制、原理）**每一块都挂了结果式总结**，或已明确降级。
- 全页无「第 N 层 / 最后这块」类失效位次词。
- 结论性内容只有一份，其余是指针。
- 删改之处**逐条报出**（删了什么、为什么），不静默删除。

## 红旗（出现即返工）

- **硬塞**：把原材料整段放在开头。用户原话："最开头这么长谁看啊"。
- **物理拼接**：说"整合融合"却只是把 A 挪到 B 后面，同一结论摆三遍。整合 = 先列重复处 → 定权威源 → 其余降级为导航。
- **参数层打转**：改了几十轮还在调服务名、机制条数、小标题，那一句买的理由仍未找到。
