# AI 味信号校准（中文）

## 核心立场

**业界结论必须先用自己的真实稿校准，再落地。照搬会判反。**

一次实测（真人 16 篇 ASR 口播稿 vs AI 69 篇）中，业界三大信号里**两个方向是反的**：
- 句长变异系数：真人 0.501 / AI 0.648（业界预期 AI 更均匀 → 实测相反）
- 连接词密度：真人 2.506 / AI 1.411 每百字（业界预期 AI 更多 → 实测相反）

唯一稳健的信号是**最长句长度**（真人 66.5 字 / AI 97 字，Cliff's delta −0.619）。

## 什么时候用

- 要给扫描器/检测器新增一条判据
- 要定阈值（T 取多少）
- 有人引用「业界都说 XX 是 AI 特征」要求照做
- 已有的判据被质疑误伤，要判断是阈值问题还是信号本身问题

## 流程（P-D-C-A）

### P｜建对照组
1. **真人组**：找「AI 参与度低」的历史稿。**优先 ASR 转写稿 / 早期手写稿**，不要拿"人审过的 AI 稿"充数（人审只改事实，不改节奏）。
2. **AI 组**：取当前生产线真实产出，**按来源分桶**（专家包产出 / 早期稿 / 其他人设），不要混成一组——混组会掩盖人设差异。
3. **样本量**：每组 ≥15 篇；低于此，所有 p 值只能当参考。
4. **去重**：同篇异版必须配对去重（相似度 >0.99 视为同篇），否则样本不独立、统计量虚高。

### D｜清洗 + 测量
清洗是最容易出错的一步，AI 稿必须剥离：
- markdown 标题 / 引用行 / 分隔线
- 元信息行（`**选题**：` `关联旧稿：` 等加粗 KV——**先去加粗再判 KV**，否则识别不到）
- 正文后的附录（`[REF-xxx]`、事实检索、待核实、版本定稿说明）——命中即**截断**
- 健康检查：剔除过短篇、剔除 HTML 外壳页（中文字数 <200）

测量指标（全部确定性、不依赖 LLM）：
| 指标 | 定义 |
|---|---|
| 句长 CV | 句长标准差／均值（按 。？！ 分句） |
| 连接词密度 | 连接词命中数／中文字数 ×100，长词优先去重 |
| 段长 CV | 段落长度变异系数 |
| **句最长** | 单篇最长句字数 ← 通常是最稳健的那一个 |
| 句长均值／中位／p99 | 定位差异在中位还是右尾 |

### C｜检验（不只看均值）
1. **中位数优先**（小样本抗偏），均值会被引用的极端值带跑。
2. **Cliff's delta** 效应量（非参数）：|δ|<0.147 可忽略 / <0.33 小 / <0.474 中 / ≥0.474 大。**只有效应量大的信号才值得做判据。**
3. **Mann-Whitney U** 出 p 值（正态近似 + 并列校正）。**p>0.05 直接判"两组分不开"，不要设阈值。**
4. 对半拆分 200 次稳健性检验，确认不是某几篇撑起来的。

**必须做的四项伪影排除**：
- **篇幅混淆**：算指标与字数的 Pearson 相关；r>0.3 就做篇幅匹配子样本重算
- **去极值**：剔掉最长句后看方向是否反转
- **词表假阳性**：连接词表逐词回看上下文，剔除多义单字（`更`/`还`/`却` 大多是程度副词或副词，不是连接词）
- **体裁混淆**：真人 ASR 口语 vs AI 书面拟口语是**硬混淆**，分离不了的信号直接判「不可用」，不要勉强

### A｜定级：warning 还是 error
跑阈值扫描，输出每个 T 的误伤率 / 召回率 / 正确率，然后看**有没有双优区间**。

经验结论：**单指标基本不存在双优取值**。例如最长句：
| T | 误伤 | 召回 |
|---|---|---|
| 65 | 56.2% | 77% |
| 85 | 12.5% | 63.8% |
| 90 | 6.2% | 60.9% |
| 105 | 0% | 37.7% |

判据：
- 存在误伤 <5% 且召回 >70% 的区间 → 可考虑 error（硬拦截）
- 否则 → **只能 warning**（报告里提示"第 X 句最长 N 字"），绝不拦截

## 硬规则

1. **阈值不全局统一，按人设/提示词分别校准。** 实测中同一 AI 生产线，何磊线 δ=−0.806、秋红线 δ=−0.253（p=0.1642 不显著）——后者设阈值就是纯误伤。
2. **p 不显著 = 这条线不设判据。** 不要因为"感觉有差异"就设。
3. **撤回要说出来。** 上一轮给的建议被新数据推翻时，显式写"撤回"，不要静默改。
4. **区分"待补语料"和"结构性不存在"。** 某条线从一开始就全 AI 产出 → 不存在真人基线 → 判据只能从别的线外推，且必须标注「可靠性存疑」，不要挂成"待补"反复提起。
5. **业界词表类信号（换词/禁用词）是已被证明最无效的维度**——换同义词不改变任何结构统计量。要动就动分布量。

## 坑

- `cv()`（变异系数）对单元素序列返回 None，`round(None)` 直接 TypeError → 调用处统一容错
- 复用别人的 `mwu()` 时先确认返回值是标量 p 还是 `(U, z, p)` 三元组
- 分句正则别用裸数字切分，正文里的 "4-6 个""2 月" 会被当编号；用 `(?<=[。？！])\s(\d{1,2})\s`
