# 欧洲两河年度趋势预判（Europe Rhine-Danube River Outlook）

## 定位

对莱茵河、多瑙河流域做**跨学科、长序列、年度级**的趋势预判，产出**下一个游轮季乃至 1–3 年的方向性趋势与背景概率**。

| 项 | 内容 |
|---|---|
| **服务对象** | 欧洲内河游轮业（同行）——决策者是行业里懂行的人，不是气象专业人士 |
| **给什么** | ① 背景概率往哪个方向移 ② 放大系数（同等天气下后果被放大多少） ③ **本窗口该做什么**（择优 / 修正 / 应对） |
| **时间尺度** | **年度级（1–3 年）**；≥12 个月窗口出**情景预演**，不给等级、不给数值 |
| **信源轨** | **跨学科长序列**（7 域）：冰冻圈 / 大气与气候系统 / 水文与河流 / 农业与粮食 / 天气与气候干预 / 经济与损失 / 同行评议文献 |
| **不干什么** | **不做 6 个月以内的决定性预报**——那是姊妹 skill `europe-river-watch` 的职责 |

> **两个 skill 的分工（一句话）**：本 skill 管「**这一年往哪个方向走**」；`europe-river-watch` 管「**这几个月该动什么**」。共用同一套项目级信源底座，但**时间尺度、信源轨、输出物口径各不相同**，不得互相替代。

> **为什么需要单独一个 skill**：年度尺度上，季节预报系统**物理上没有输出**（ECMWF 与 Météo-France 的季节系统积分只到 7 个月）。该尺度唯一能用的，是**慢变量**——陆地水储量、冰川质量平衡、多年降水亏缺累积。这套变量与判据，与 6 个月内那套（积雪、水位、季节预测）**完全不是一批**，故必须分轨。

## 方法（本 skill 的核心）

### 一、慢变量定基线

年度尺度的地基不是「明年天气怎样」，而是「**缓冲垫还剩多厚**」：

| 慢变量 | 出报主体 | 用法 |
|---|---|---|
| **陆地水储量异常（TWS）** | GRACE-FO（GFZ / NASA / DLR，已进 GDO） | 连续负距平 → 基线恶化 |
| **冰川质量平衡** | GLAMOS（瑞士科学院） | 年消融超阈值 → 融水缓冲下降 |
| **多年降水亏缺累积** | SPEI-24 类长累积指数 | 长预见期最有效的预测因子 |
| **深层土壤水** | SSMI-L4（UKCEH） | 持续低位 → 干旱后果被放大 |

**基线输出的是「背景概率上移 + 放大系数」，不是事件本身。** 它改变的是**条件概率**——只能说「同等天气条件下，后果会被放大 N 倍」，**不能说「明年夏天会旱」**。

### 二、条件线配对（**硬纪律**）

> **基底层必须与「条件线」配对，否则退化为常驻悲观句。**

- **无条件** → 只给**常驻背景**（缓冲垫厚度 + 放大系数），一句话带过，**不重复发警报**。
- **有条件**（ENSO 相位转换年 / 冬季 NAO 信号 / 极端积雪亏缺）→ 升级为**条件性方向预演**，此时才给方向与概率。
- 判据：可预报性**是有条件的**（冬季 NAO 一年前的可预报性，仅在 ENSO 转换年相关可达 0.60，稳定年近 0）。

### 三、提前期 × 可信度（衰减曲线）

**可预警提前期不由模型强弱决定，由「你问的变量有多慢」决定。变量记忆越长 → 可预报提前期越长。**

| 区间 | 提前期 | 可信度 | 能说什么 |
|---|---|---|---|
| 可行动区 | 1–2 个月 | 70–85% | 等级 + 区间 + 时点窗口 |
| 方向区（主推荐） | **3–6 个月** | **55–70%** | 方向 + 影响面 + 放大系数 |
| 基地区 | 1–5 年 | 60–75% | 只给「缓冲垫厚度」与放大系数，**不给年份** |

**超过 1 年的尺度，可信度反而回升**——因为预报对象从「某年天气」变成「缓冲垫还剩多厚」，慢变量的趋势比年际变率好预测得多。这是基底层存在的量化理由。

**两条形态特征**：① **事件越极端，可用提前期越长**；② **可预报性是有条件的**——不可假设「每年都能提前一年预警」，必须逐年判断「今年踩到可预报条件了吗」。

### 四、类比年法

把「方向」翻译成「历史上长什么样」（如 2026/27 冬对比 1982/83、1997/98、2015/16）。

**报告结尾必须有一节完整列出长期跟踪的信源池**——不是一句话带过。

- **不管本期信源有无更新，这一节都要出现**；有新源则追加，无新源则原样保留。
- 分组陈列最权威的几组信源（条约级航运机构 / 联合国专门机构 / 欧盟体系 / 主权国家官方机构 / 同行评议文献），**每条三行**：
  1. **中文全称（原文全称 / 缩写）**
  2. **法理依据**（条约名+生效年 / 设立法规 / 期刊+作者单位）

## 信源纪律

1. **只有 A 级可定级**；B 级只作领先提示，D 级只作舆情背景。
2. **新信源入 B 级前必须核验出报主体**（官方全称 + 法理依据/工商主体）；核验不到的一律只作 D 级参考。
3. **降级触发器**（v1 只有入级、没有退出）：① 出报主体性质变化；② 方法不透明；③ 与 A 级源长期冲突且无法解释；④ 停止更新 >1 年。
4. **已知置信度限制（引用时须一并说明）**：C3S 季节预测在欧洲技巧官方自认偏低；EDO 土壤湿度 2025-05 起东欧部分区域有已知精度问题；PEGELONLINE 为未校验原始值。
5. **信源时效性逐条核 URL 日期**：检索结果里出现过期文件被当新结果推送的实例（曾有三条源误称 La Niña，其中一条 URL 自带 `september-2020` 旧文件）→ **不得因排名靠前就采信**。
6. **AI 气象模型不得作年际锚点**：ECMWF 已停止实时跑外部 AI 模型；此类模型对初始场高度敏感，**只作短中期辅助**。

`出报主体中文全称（原文全称 / 缩写）.《页面或报告标题》. 发布或更新日期. 完整 URL. 〔本库检索日期：YYYY-MM-DD〕`

- **两个日期都要写**：「发布/更新日期」属信源，「检索日期」属本库——网页会改会删，检索日期是「当时确实如此」的唯一凭证。
- **二手必回溯一手源**，并标出经由哪个二手渠道看到。
- **学术引用给到卷(期):页 + DOI**；只给「某研究显示」= 不可定位 = 不可引用。
- **版权边界：转述结论，不搬运表达**——整段搬运 ❌（即使标源）；第三方图表/图片/地图原图直接复制 ❌（改自制图表 + 标数据源）。

## 工作流（每次运行 = 四段闭环）

### 第一段：读底座（不重复劳动）

1. 读项目信源库、权威性核验、职称补核三份文件。
2. **优先复用 `europe-river-watch` 当月的巡检产出**（巡检报告 + 信源库增量）——同一套底座，不重复检索。

### 第二段：基线取数（慢变量）

3. 取慢变量当前状态：TWS 异常、冰川年消融、长累积降水指数、深层土壤水。
4. 判「缓冲垫厚度」——**只给背景概率与放大系数，不给年份**。

### 第三段：条件线判定（**不许跳过**）

5. 判「今年踩到可预报条件了吗」：ENSO 相位、冬季 NAO 信号、极端积雪亏缺。
6. **未踩到 → 只给常驻背景，不发方向警报**（基底层不许单独出结论）。

### 第四段：出报告与回写

7. 按「时间维度 × 输出物」出对应类型报告（情景预演 / 条件预演）。
8. **尾节「长期跟踪信源池」必现**（无新源则照旧保留）。
9. 新信源靶向补进信源库对应分级 + 补全标注 + 追加权威性核验。

### 年度动作

10. 每年 9–10 月做完整年度预判（冬季展望窗口）：慢变量年度更新 + 复核对下一游轮季的趋势判断。
11. 与姊妹 skill 交接：年度复盘结论同步给 `europe-river-watch`（它承担 6 个月内的决定性子预报）。

## 红线

- **不得把低置信背景包装成当期判定**：≥12 个月窗口**不给等级色、不给具体数值**（那是假绿）。
- **基底层不许单独出结论**：必须配条件线，否则退化为常驻悲观句。
- **不得越界做 6 个月内的决定性预报**：那是 `europe-river-watch` 的活，避免两处口径分叉。
- **背书红线**：不得出现未展开的英文缩写；不得出现「据官方数据」「据研究」这类不点名表述。**不点名 = 无效报告**。
- **出线红线（版权合规）**：每条引用必须带出处四件套；禁止只给域名 / 只给首页 / 只写「近期」/ 只挂二手 / 整段搬运 / 直接复制第三方图表原图。
- **动作红线**：任何一期报告，除「有多严重」外，**必须给出「本窗口该做什么」**（择优 / 修正 / 应对）。
- **信源池红线**：报告尾部「长期跟踪信源池」节**每期必现**。
- **不得把「公开可得」当「可引用」**。
