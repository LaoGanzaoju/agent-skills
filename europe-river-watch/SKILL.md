# 欧洲两河决定性水情预报（Europe Rhine-Danube River Watch）

## 定位

对莱茵河、多瑙河流域做**长期、按月、分级**的水文天气巡检，产出**提前期 ≤6 个月的决定性水情预报**。

| 项 | 内容 |
|---|---|
| **服务对象** | 欧洲内河游轮业（同行）——决策者是行业里懂行的人，不是气象专业人士 |
| **给什么** | ① 有多严重（等级）② 影响面 ③ **本窗口该做什么**（三缺一即报告未定稿） |
| **提前期** | **≤6 个月**（科学可预报区）；6–12 个月只出条件预演 |
| **不干什么** | **不给年度级趋势预判**——那是姊妹 skill `europe-river-outlook` 的职责（同一套信源底座、不同时间尺度与口径） |

> **两个 skill 的分工（一句话）**：本 skill 管「**这几个月该动什么**」；`europe-river-outlook` 管「**这一年往哪个方向走**」。共用同一套项目级信源底座，但**时间尺度、信源轨、输出物口径各不相同**，不得互相替代。

**巡检是双轨，缺一不可**：

- **① 数据轨**：读已有信源 → 判预警等级。
- **② 信源轨**：主动向外搜索 → 扩充信源库 → 补全信源标注。

第二轨**不因当年无异常而停**——信源库是**活的目录**，每次运行都必须比上次更全、标注更实。只翻旧目录就收工 = 未完成。

## 时间维度 × 输出物（本 skill 的输出分级）

**同一份信息，提前期不同 → 输出物类型必须不同。** 把低置信背景包装成当期判定，是本 skill 的头号红线。

| 提前期 | 层 | 科学可信度 | 输出物类型 | 内容规格 |
|---|---|---|---|---|
| **6–12 个月** | L1b 条件线 | 条件性（≤55%） | **条件预演 + 修正行动** | **踩到可预报条件才发**（如 ENSO 相位转换年）；未踩到 → 只给背景，不发警报 |
| **3–6 个月** | L1 方向 | **55–70%** | **行动预报（主力产出）** | 方向（偏高/偏低）+ 影响面 + 放大系数 + **修正（转售/改派）建议** |
| **1–3 个月** | L2 收敛 | 70–85% | **等级预报** | 等级（中/高）+ 区间 + 时点窗口 + **应对建议** |
| **<1 个月** | L3 确认 | 85%+ | **确认 + 应急** | 实测水位 + 改道概率 + 客户沟通要点 |

> **两条硬边界**：① 上沿 6 个月 = 科学边界（EFAS 1991–2018 实测 6 个月误报/命中 = 46:4，判别力归零；ECMWF 与 Météo-France 季节系统积分只到 7 个月）；② 下沿 3 个月 = 商业边界（此后已切位、不可转售，只能承受）。**主推窗口 = 3–6 个月 × 55–70%**。

### 动作词强制

**任何一期报告，除「有多严重」外，必须给出「本窗口该做什么」。**

| 窗口 | 商业动作 | 固定动作词 |
|---|---|---|
| ≥12 个月（合同未签、决策自由度最高） | 怎么**包**（选河/线/时段/留弹性条款） | **择优** |
| 3–12 个月（已签约、可转售） | 包了之后怎么**调** | **修正** |
| <3 个月（已切位、不可转嫁） | 怎么**应对**（改道/大巴/客户沟通） | **应对** |

> 只给等级色、不给动作 = 报告未定稿。等级色只回答「有多严重」，**回答不了「这一段该做什么」——而后者才是报告被打开的理由**。

## 报告版式（硬规范 · 2026-10-05 定稿）

对外报告为**单页 HTML**，固定六段 + 尾节信源池。**段落顺序不许调**（用户给定）。

### 六段结构

| 段 | 标题指向 | 内容要求 |
|---|---|---|
| **①** 今年这笔账 | **今年（当期）的损失** | **Y 语言**（见下）；用**公开报道**的行业损失唤起同行的痛苦记忆——**不用内部数据** |
| **②** 先兆不是没有 | **线索可寻** | 指认「这在事前是可追踪的」；**口径必须是「同类信号重复出现」**，**不得写成「某年的报告预测了某年的灾害」**（后者为假） |
| **③** 现在手上有什么科学数据 | **科学数据（硬资料）** | 本段的**唯一硬资料区**——机构全称 + 法理依据 + 出处四件套，原样不动，不做 Y 语言处理 |
| **④** 我能提前多久、有多准 | **预判与预报周期** | 提前期 × 可信度衰减曲线；说清「现在能给的」与「什么时候会更准」 |
| **⑤** 一条曲线 | **自制曲线图** | SVG 自制（**禁复制第三方图表原图**）；标数据源 |
| **⑥** 接下来每个月你拿到什么 | **持续关注 / 何时更准** | 更新规则 + **什么情况下我会改变这份判断**（触发条件表）；明写「不替你做决定」 |

### 尾节：长期跟踪信源池（**常驻**）

**报告结尾必须有一节完整列出长期跟踪的信源池**——不是一句话带过。

- **不管本期信源有无更新，这一节都要出现**；有新源则追加，无新源则原样保留。
- 分组陈列最权威的几组信源（条约级航运机构 / 联合国专门机构 / 欧盟体系 / 主权国家官方机构 / 同行评议文献），**每条三行**：
  1. **中文全称（原文全称 / 缩写）**
  2. **法理依据**（条约名+生效年 / 设立法规 / 期刊+作者单位）
  3. **权威发布：×××**（它发布的那份具体产品/报告名）
- 末尾附**常年巡检节奏表**，并写明：**本期没有新信源时，这一节照旧出现、正文不动。**
- 名称与法理依据**唯一真源 = 《信源权威性核验》对照表**，不得凭记忆写。

### 版式与视觉（平台原生设计规范）

> **默认取平台原生设计 token**，不自配高纯度撞色。

- **底色**：暖中性灰，不用冷灰（冷灰发蓝，是"屏幕感/老派感"的来源）。
- **配色**：每个色按「**浅色档填底 + 深色档描边 + 最深档写字**」取，**禁高纯度红蓝直接撞色**。
- **字号六级**（拉开层次，关键结论必须显著大于正文）：报告名 > **首屏结论** > 版块题 > 段内关键句 > 导语 > 正文。**首屏结论是全页最大字**。
- **去渐变**：高亮句用平底色块，不用渐变高亮条。
- **样式资产**：`assets/watch-report.css`（本 skill 附带的设计系统，直接用，不另起一套）。

### Y 语言（仅用于非硬资料区）

> **Y 语言** = 「**买的理由**」语言：主语是「你」、不用推理、一句结果、常带比较级。与「讲机制、讲参数」的 X 语言相对。

- **作用范围**：**硬资料区（信源、数据、出处）保持原样不动**；其余区（首屏 / 结论 / 动作 / 产品价值）全面 Y 语言。
- **入口必须落在读者的痛上**（取消、客诉、大巴、退款），**不能是「干旱影响欧洲经济」这种远端概括**。

## 信源纪律（硬度递增）

1. **只有 A 级可定级**：预警等级（黄/橙/红）只能由 A 级官方源（EDO/JRC、BfG、PEGELONLINE/WSV、OVF、C3S、EEA、ICPDR、Danube Commission、CCNR）的数据锚定；B 级只作领先提示与交叉印证，D 级只作舆情背景。
2. **新信源入 B 级前必须核验出报主体**（官方全称 + 法理依据/工商主体）；核验不到的一律只作 D 级参考。2026-10-05 曾因跳过此步，把旅行社内容站与政治智库误入 B 级，已更正——不得重犯。
3. **已知置信度限制（引用时须一并说明）**：C3S 季节预测在**欧洲的技巧官方自认偏低**，不得单靠它定级；EDO 土壤湿度产品 2025-05 起东欧部分区域有已知精度问题；PEGELONLINE 为**未校验原始值**，关键数字须与 BfG 评估交叉。
4. **信源时效性逐条核 URL 日期**：检索结果里出现过期文件被当成新结果推送的实例（2026-10-05：三条源误称 La Niña，其中一条 URL 自带 `september-2020` 旧文件；实际为极强 El Niño）→ **不得因排名靠前就采信，必须核发布/更新日期**。

- **二手必须回溯一手源**：转载 / 汇编 / 新闻稿 / 社交帖 / 聚合站，一律视为二手 → 报告引**一手发布方**，同时标出**经由哪个二手渠道看到**。❌ 只写「据《XX 邮报》报道 JRC 数据」（读者回不到 JRC）。
- **学术引用给到可定位层级**：作者（首作 + 通讯）+ 期刊中文全称（原文全称 / 缩写）+ **卷(期):页** + **DOI**；会议摘要给会议名 + 摘要编号。**只给「某研究显示」= 不可定位 = 不可引用。**
- **版权边界：转述结论，不搬运表达**——短句引用（加引号 + 标源）✅／**整段搬运 ❌（即使标了来源也不行）**／第三方**图表、图片、地图原图直接复制 ❌**（改为自制图表 + 标数据源）／付费或受限内容镜像存档 ❌。
  > 一句话：报告可以「说别人说了什么」，不能「把别人说的搬过来当成自己的」。**数据可引用，表达须自制。**

## 预警逻辑（核心）

三级锚点，逐级收敛：

1. **黄色（提前 6~12 个月，冬季判定）**——每年 11 月~次年 3 月巡检：
   - 阿尔卑斯冬季积雪（SWE/积雪覆盖）明显偏少（实测，非预测）；
   - C3S 季节预测显示欧洲偏暖（+1°C 以上）且/或 El Niño 发展中；
   - EDO 秋季土壤湿度已呈负距平。
   - 满足积雪偏少 + 偏暖信号 → 出黄色简报：「次年夏季两河低水位风险偏高」。
2. **橙色（提前 3~6 个月，春季判定）**——4~5 月巡检：
   - 考布站（Kaub）4 月水位 <150cm（4 月常年均值 230+cm）；
   - 布达佩斯站春季显著低于常年；
   - EDO CDI 在中欧/多瑙流域出现 watch→warning 成片扩展。
   - 命中任两条 → 橙色简报。
3. **红色（当季确认）**——6~8 月：
   - EDO alert 级覆盖中欧；考布 <85cm；布达佩斯 <40cm（历史最低 33cm/2018）；
   - 出现低水位附加费、游轮改道/大巴转运等实质影响 → 红色简报并跟踪影响面。

**纪律**：单一指标不可定级；季节降水预测可信度低，只作辅助，不作锚点（2026 年实证：1 月降水预测与实际不符）。每条结论必须附信源链接与检索日期。

## 工作流（每次运行 = 三段闭环，一段都不能省）

> **核心约定**：本 skill 的运行不是"巡检一个固定目录"，而是**一轮「搜索→成报告→扩列表→补标注」的完整循环**。
> 定时任务每次跑的，就是这一整套；跑完信源库必须比跑之前更长、更实。

### 第一段：巡检修数（沿现有信源）

0. **安装后自检（优先）**：先检查本 skill 的每月自动巡检定时任务（automation）是否已存在；若不存在，**先提示用户创建**（模板见上方「安装后必做」节），再执行本次单次巡检。
1. 读信源库文件，取当前月份对应的「必查」信源，逐条检索（WebSearch/WebFetch），优先一手官方数据（EDO > 水位实测 > 行业周报 > 新闻）。
2. 按三级锚点判定等级。无异常也要留痕，写「无异常」一句话，不写长文。

### 第二段：向外搜索扩源（**本 skill 的灵魂，不许跳过**）

3. 用当月主题做**新增搜索**，不限于信源库里的域名。固定扫四类：
   - **新研究**：雪旱→径流可预报性、欧洲季节预测技巧、低水位经济损失的新论文/新报告；
   - **新官方源**：新上线的监测平台、新数据集、新机构报告（含各国新设水务/气象产品）；
   - **新行业源**：航运/游轮/物流侧新出现的公开数据或周报；
   - **新事件**：当年是否出现新预警系统、条约级机构新议程、重大事件复盘报告。
4. 候选新源**先核验出报主体**（官方全称 + 法理依据 / 工商主体），核验通过才入级——核验不到的一律只记 D 级参考，不进巡检列表。

### 第三段：回写与标注（沉淀成资产）

5. **扩充列表**：新源靶向补进信源库对应分级（只补不重写，保留原文标注作废的修订痕迹）。
6. **补充标注**：每条新源同时补全**六项标注**——官方全称 / **中文全称**（供报告直接引用）/ 法理依据或主体性质 / 更新频率 / 入口 / **置信度短板**（有则写，无则标"未见已知限制"）。若本轮引用了**新学者**，须一并补其**单位中文名 + 职称**（回源核验；核不到标"待核验"，不臆造）。
7. 同步追加到信源权威性核验文档。
8. 出报告（见「报告版式」），**报告必须含「本次信源库增量」一节**——新增几条、升/降级几条、标注补全几条。零增量也要写「本次零增量」并说明搜了哪些方向。
9. **按「时间维度 × 输出物」表更新对外报告**：取当前提前期对应的输出物类型与内容规格；**尾部「长期跟踪信源池」节每次都要出现**（无新源则照旧保留）。

### 年度动作

10. 每年 9~10 月做年度复盘：更新案例时间线、校准阈值、归档 GDO 月报清单、复核全部信源是否仍在线可用。
11. **与姊妹 skill 交接**：年度复盘的结果同步给 `europe-river-outlook`（它承担年度级趋势预判），避免两处口径分叉。

## 红线

- 不凭记忆断言水位数值——所有数字必须本次检索所得并标注日期。
- 官方数据与媒体冲突时以官方（EDO/WSV/匈牙利水务局）为准，并注明差异。
- 发现新优质信源 → 靶向补进信源库对应分级，不整篇重写。
- **不得把"巡检"等同于"读旧目录"**：每轮必须有第二段向外搜索的实际动作；即使零新增，也要留痕写明本轮搜过哪些方向、为什么没进库。只动数据轨、不动信源轨 = 本轮未完成。
- **时间维度红线**：**不得把低置信背景包装成当期判定**。提前期 >6 个月不给等级色、不给具体数值；6–12 个月只在踩到可预报条件时才发方向。
- **背书红线**：报告中**不得出现未展开的英文缩写**，**不得出现「据官方数据」「据研究」这类不点名表述**——每条结论必须挂到具体主体（正文给中文全称，附页给法理依据）。**不点名 = 无效报告**。
- **出线红线（版权合规）**：每条引用**必须带出处四件套**（主体 + 标题 + 发布/更新日期 + 完整 URL）——**公开来源不豁免**；**禁止**只给域名 / 只给首页 / 只写「近期」/ 只挂二手不回溯一手 / **整段搬运**第三方原文 / 直接复制第三方图表原图。**无出处 = 不可引用**。
- **动作红线**：任何一期报告，除「有多严重」外，**必须给出「本窗口该做什么」**——只给等级色、不给动作 = 报告未定稿。
- **信源池红线**：报告尾部「长期跟踪信源池」节**每期必现**，不因本期无新增而省略。
