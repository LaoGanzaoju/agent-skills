## 1. 五手段详版

### 手段 A · 拆 + 外移（主力手段）

**适用**：项目级记忆、用户级记忆、身份三件套这类"用户自己写的正文文件"。

**步骤**：
1. **备份**：先把原文件复制一份到归档位置（带日期），**再动手**。
2. **划黄金区**：留下"每次开工都必须看到"的部分 —— 通常是：当前主线状态 / 铁律 / 高频纪律 / 索引指针表。
3. **整块切出去**：把历史事件、已完成的过程记录、一次性分析，**整节完整地**搬到同级外移件。
4. **留指针行**：主文件里每一块被搬走的内容，留一行"XX 见 `外移件名`"。
5. **命名**：同级目录、`<对象>_外移_<年月>.md`。
6. **重测**：跑体检脚本，确认主文件落到目标区间。

**目标区间**：上限的 **80% 以内**（8000 → ≤6400）。留 20% 是给"接下来的正常追加"用的 —— 压到刚好 7999 等于下周就要再来一次。

**三条纪律**：只搬不删 · 内容零改动 · 外移件与主文件同级（否则下次找不到）。

**两级退场（一级做不动就上二级，别硬砍）**：

| 级 | 触发线 | 动作 |
|---|---|---|
| **一级** 整节外移 | 该槽 ≥ 上限 **95%** | 整节完整搬到同级 `*_外移_<年月>.md`，原位留 **1 行可跳转**的指针 |
| **二级** 节内密度约束 | 一级之后**仍 ≥95%**；**或单节 > 该槽上限的 20%**（8000 → 1600） | 节内**过程数据**下沉到外移件；主文件保留「**1 行指针 + 全部跨任务可复用条目**」 |

**二级的判据只有一条**（**不是**"重不重要"、**不是**"看着长不长"）：

> **这条内容下一次别的任务还用不用得上？**

- **用得上**（跨任务可复用的纪律 / 口径 / 陷阱 / 判例）→ **上浮**，留在主文件。
- **只用一次**（项目过程数据：档案清单、本项目数字、一次性内参、结论推导过程）→ **下沉**到该节的外移件。

⚠️ 二级**不是**"删节、只留一行指针"：下沉的内容必须**完整落进外移件**（不减字、不摘要），
主文件留的指针必须是**真路径**。**硬红线**：不完整＝信息真丢，指针不可跳转＝下次重复做功。

**什么时候别用一级**：对象是**密度型饱和**（此前已多次压缩、有效内容占比高）时，一级只能挪走水分 —— 实测某项目只降 6.6%。
这时**直接转二级**，不要反复一级、也不要逐条砍。

**反例**：把内容**删掉**（信息真丢了）；把外移件放子目录深处（等于隐藏）；搬完不留指针（下次重复做功）。

### 手段 B · 节流 + 写前预算

**适用**：所有"会持续增长"的记忆文件。

**做法**：**每一次写入前，先量当前长度**，再决定这次内容写哪儿：

```
量当前长度 → 余量够？ → 写入主文件
                   ↓ 不够
              改写进外移件 / 另一层（就低不就高）
```

**为什么必须**：记忆文件的增长是**累积式**的。一次"就多写 200 字"看起来无害，十次就越线。而且越线后是**静默截断**，你不会知道。

**配套**：在每天的收尾动作里带一句"今日写入后工作记忆 = N / 上限" —— 让漂移可见。

### 手段 C · 结构瘦身（目录清单槽专用）

**适用**：目录清单槽满 40 条、新文件在界面上看不见。

**核心认识**：**这是"可见性"问题，不是磁盘空间问题。** 文件还在，只是列不进那 40 条。

**做法**：把**过程件**收进子目录 —— 典型候选：
- 备份 / 快照 / 归档（`*_备份_*`、`*_快照_*`、`归档_*`）
- 试点 / 样张 / 对比页（一次性产物）
- 阶段性执行留痕

**做之前确认三条**（避免误伤）：
1. 只动**不需要在主目录里被一眼看到**的东西。
2. **方法论资产、索引、入口文件一个都不能动。**
3. 内容零改动，只改位置。

**验收**：根目录非隐藏条目数 ≤ 40，且被移走的文件在新位置可正常打开。

---

### 手段 D · 换入口 / 用开关（平台侧对象）

**适用**：云档案这类"不是你写的"的槽。

**顺序**：① 找平台是否提供开关 → ② 有则用开关并记录代价 → ③ 没有则**接受**，并在报告里说明"此槽不可治，已知会截断，影响范围是 XX 段"。

**禁止**：用改文件权限、切断网络、伪造缓存之类的"硬堵"手段。这类槽背后通常有**轮询同步**机制，硬堵会造成锁冲突或数据回灌。

---

### 手段 E · 仅立规则（不动手）

**适用**：空槽、非用户资产的槽（二进制环境信息、目录清单本身）。

**做法**：不治理，只写一条自律线，例如"某文件一旦启用，即 ≤6400"。写进规则文件，让后续所有会话都看到。

## 2. 槽位归位例

**判断顺序**（照此问）：人是谁 → 项目是什么 → 行为纪律 → 说话习惯 → 都不是就别塞。

| 你想放的内容 | 应归 | 为什么 |
|---|---|---|
| "回复一律用中文，路径给完整纯文本" | 个人指令 | 个人说话/格式习惯，跨全部会话生效 |
| "改文件前先整篇读，只做靶向补丁" | 项目规则 | 行为纪律，语义正是"当作亲口说的来遵循" |
| "这个项目是 XX 系统的重构，跑法是 XXX" | 项目说明 | 项目说明书 |
| "我是谁 / 我的助手是谁 / 用户是谁" | 身份三件套 | "体现其人设与语气" |
| "上周发现某工具的收集函数有缺口" | **哪个都不放** | 这是**结论**，放记忆或文档；塞进槽 = 浪费首轮预算 |

**两个高频误判**：
- **"把重要的都写进身份三件套"** —— 三件套装的是**稳定内核**（人是谁），不是工作法。工作法放规则或 skill。
- **"军规写成带 `paths` 的条件规则"** —— 条件规则**当前不生效**，关键纪律会静默失效。写成普通 `.md`。

## 3. 跨机迁移清单

> ⚠️ **先确认是"搬"还是"装"**：目标端**没有任何现成内容** → 那是**首装**，走 `first-run-setup.md`。
> 本节只处理"源机有、目标端要收"的情形；若**只有三件套**需要重写，先按首装写三件套，其余照本节搬。

### 3.1 先分类（这一步做错，后面全错）

| 类 | 判据 | 搬不搬 |
|---|---|---|
| 云侧 | 同账号即回 | **不搬** |
| 随项目 | 挂在项目目录里 / 进 git | **随目录走** |
| **机器本地** | 只在 `~` 下 | **必须手工搬** |

### 3.2 机器本地项逐项核对（带 ✅ 用）

- [ ] 身份三件套（SOUL / IDENTITY / USER）
- [ ] 用户级记忆主文件
- [ ] 用户级记忆的**外移件目录**
- [ ] 规则目录（用户级；项目级规则随项目走）
- [ ] 配置里的**个性化段**（口吻/个人指令）
- [ ] skills 目录
- [ ] 连接器 / 授权（这一项**通常不能靠拷文件解决**，目标端要重新授权）

### 3.3 顺序硬约束

**先拷文件，后启动客户端。** 平台的初始化写入是"**只补缺、不覆盖**"式的：
- 先拷 → 平台一字不动，直接认。
- 后拷（先让平台生成了默认模板）→ 你要手工合并，且可能覆盖掉你写的。

**验收信号**：内容 ≠ 默认模板时，平台会**直接记为"已完成引导"**，不会再来问一轮"你是谁"。**没出现引导流程 = 迁移成功的信号之一。**

### 3.4 搬完必做

- [ ] 逐项比对**目标端实际落地**（不是"我拷了"，是"它在那儿且内容一致"）
- [ ] 打开新会话，看注入块里**是不是这些内容**（这才是"真的生效"）
- [ ] 连接器重新授权、跑一次冒烟

> ⚠️ **工具的文档不可信，收集范围要读它的实现。** 已知有工具文档写"记忆由云端同步"，实际实现只收某一类文件、**不收根目录下的本地记忆与外移件** —— 照文档操作会静默丢数据。

## 4. 报告模板（给非程序员看）

治理结果一律按这个结构出，**不要写成叙述**：

```
结论：<一句话，越线对象几个、是否清零>

一、体检结果（数字表）
   对象 | 现值 | 上限 | 余量 | 判定

二、本次动作
   对象 | 手段 | 前 → 后 | 落点文件

三、验收
   信号（可跑命令 + 可观察结果）
   负控制：造越线对象 → 脚本报红 ✅

四、未解决 / 待定
   对象 | 为什么没治 | 谁决定
```

**四条出报告纪律**：
1. **结论先行**。
2. **凡数字必重测**（改动会漂移，旧计数作废）。
3. **区分"静态已证"与"动态未证"** —— 文件内容/字符数当天可证；"是否真注入"必须等下一会话开局看注入块。
4. **负控制单列**：只能绿不能红 = 假绿。

## 5. 一个疗程的标准路径（照抄）

```
① 备份          cp 原文件 → 归档（带日期）
② 体检          跑脚本，得到分级表
③ 判定          只挑 A≥🟠 且 B=✅ 的
④ 归位          先判"该不该在这层"，再谈瘦身
⑤ 手段 A→C→B    先一级外移、再二级密度约束、再结构瘦身、最后立节流
⑥ 重测          数字必须变
⑦ 负控制        造假越线对象，脚本必须报红
⑧ 记录          写进当日日志 + 更新交接件；报告里数字重测
```
