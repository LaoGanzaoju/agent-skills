九、注入层自律：越线之前先叫

本机所有会话在**写入任何注入对象**（项目级 / 用户级记忆、身份三件套、规则文件、个人指令）时遵守：

- **写前先量**：动手前取现值。🔴 / 🟠（≥95%）**先退场再写入**；🟡（≥80%）可以写，但写完须复核未越线。**退场目标**＝落回该槽上限的 **80%** 以内（留出正常追加的余量）。
- **只认字符数**：项目级记忆 8000 ／ 用户级记忆 4000 ／ 身份三件套 10000 每件 ／ 规则 40000 每件 ／ 个人指令 1500。**行数、字节都不是注入单位**。
- **分级**：🔴 >100% 当场止血（平台已在截断或丢弃）｜🟠 ≥95% 本波做退场｜🟡 ≥80% 登记观察｜🟢 <80% 安全。
- **两级退场**：一级 ＝ 整节外移到同级 `*_外移_<年月>.md`，原位留一行**可跳转**的指针；二级 ＝ 节内密度约束，判据是「**这条内容下一次别的任务还用不用得上**」—— 用得上留在主文件，只用一次的下沉到外移件。
- **只搬不删**：外移件与主文件同级；内容零改动；主文件留**真路径**指针。
- **报告不写回记忆**：体检结论落独立文件 —— 别让报告本身撑爆被治理的对象。
- **收尾看一眼**：收尾时读一次当次体检结论；见到 🔴 就当场治，不留到下个会话。
- **退场要授权**：脚本**只读 + 只写报告**；改动注入对象正文一律由人授权后执行。
- **配置走界面**：个人指令这类平台配置项在界面上改 —— 直接写配置文件既不生效、又会被覆盖。
