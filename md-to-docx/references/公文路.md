# 公文路 · tencent-docx（beautify_only）

**只在轻量路不够时走这条。** 它重、有编排、有陷阱，但能套公文/报告版式模板、做字号分级。

## 为什么重

它是一条**多 Stage 编排管线**（不是一次转换调用）：

- 编排层 = `tdoc-orchestrator` skill，承接两个入口：`full_pipeline`（S1 创作 → S2 美化 → S3 转换）/ `beautify_only`（S2 → S3）。
- **转 md 必须选 `beautify_only`**：跳过 S1 创作阶段，内容才不被改写。选 `full_pipeline` 会被重写。
- 编排规则要求 Stage 0 建目录+写溯源、每 Stage 切角色、子 Agent 各读自己的契约文件。

子技能（同一插件包内）：`brief-compose` / `format-extract` / `doc-typeset` / `html-to-docx` / `html-review` / `design-token` / `generate-fillable-contract-html`。

## 三个必须知道的坑

### 1. 段落级样式必须用类选择器（头号陷阱）

`html-to-docx` 的段落级样式（`text-indent` / `margin` / `line-height` / `font-size`）走「style_injector 内联 → body_paragraph_styler 套用」链路，而 **style_injector 不处理裸标签选择器**：

| 写法 | 结果 |
|---|---|
| `p { text-indent: 2em; }` | ✘ **转换后无 `w:ind`**（静默丢失首行缩进） |
| `p.body { text-indent: 2em; }` | ✔ `w:ind w:firstLine="480"` |
| `<p style="text-indent:2em">` | ✔ 同上 |

→ 写 `doc-typeset` 的 HTML 时，**段落级样式一律挂 class**。

### 2. 模板只取版式层

`government-doc` / `business-report` 这类模板**只取版式，勿原样套用**——否则会凭空新增模板自带的文字（封面、落款等）。

### 3. html-review 门禁

门禁里与「保真」冲突的项，可**留痕放过**，不要为了过门禁去改内容。
